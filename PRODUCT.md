# Sadman's Parable

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Implementation decision: Three.js and plain JavaScript, bundled locally with esbuild. Offline Windows launchers and an offline HTML edition; no account, remote service, or CDN.

## Users
Sadman, playing on his Windows PC. Keyboard and mouse first-person exploration.

## Product Purpose
An original, playable game inspired by the narrative agency and unreliable narration of The Stanley Parable. Psychologically weird, mildly ragebaity, and filled with wonder. The expanded storyline is a connected mystery rather than a set of gags: the Department of Almost has a file for Sadman that predates Sadman, and the building has been running the same procedure since the person before him stopped answering.

## Brand Commitments
User-requested name: Sadman's Parable. Sadman is the protagonist. Inspiration is structural, not copied dialogue, characters, recordings, or level layouts.

## Capabilities and Constraints
All deliverables on E:. Manual player control by default. Local only; no publishing or uploads. Original authored world, narrative, textures, and synthesized ambient audio. Narration subtitles are always available, with optional built-in local browser speech. Game settings and discovered endings are stored locally where permitted.

## Implementation Assumptions
Desktop browser delivery rather than a native engine executable. Short replayable routes through a larger branching world. Ragebait is bounded and fictional; pause, settings, and leaving the game remain honest. No jump scares or flashing effects required.
